# Asset sources

- `anyi-wordmark.png`: the existing handwritten Anyi wordmark, bird and heart from [anyiai-docs](https://github.com/Easesgr/anyiai-docs/blob/bcd2201988682aed1459ee1c7e91d356b6e60c97/src/.vuepress/public/logo.svg). Its original shapes are preserved; the header renderer uses a lighter ink for the dark background.
- `hero*.gif` and `hero*-static.png`: original deterministic graphics rendered by `scripts/render_assets.py`. The three paths represent research, tools and learning. They are decorative diagrams, not experimental data.
- `deraining.gif` and `deraining-static.webp`: paired crops from the first and fifth columns in the top row of [MSLKAD Fig. 3](https://github.com/Easesgr/MSLKAD/blob/main/assets/figures/real-world-comparison.png), respectively Input and Ours. Both crops use the same pixel dimensions. A moving divider reveals the existing figures; no restoration or enhancement is generated by this profile.
- `dialogue-preview.webp`: resized [Dialogue Converter screenshot](https://github.com/Easesgr/dialogue-converter/blob/main/docs/images/demo.png), which shows a synthetic task.
- `learning-preview.webp`: resized [learning-site homepage screenshot](https://github.com/Easesgr/anyiai-docs/blob/bcd2201988682aed1459ee1c7e91d356b6e60c97/docs/screenshots/home.png), captured on 2026-11-08.
- `fonts/`: Manrope, distributed under the included SIL Open Font License.

To regenerate the assets:

```sh
python3 -m pip install -r requirements-assets.txt
python3 scripts/render_assets.py
```

Source screenshots are cached in the ignored `output/research/` directory. The GIFs include source comments; PNG/WebP derivatives include source metadata. The README selects static assets for reduced motion and uses a separate narrow-screen header composition.
